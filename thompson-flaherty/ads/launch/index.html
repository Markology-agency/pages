Overview

The strategic finding

SEMrush data on 23 Chicago neighborhoods + 7 Metro East spoke towns shows the same pattern: people search the head term (cpa chicago, cpa st louis), not the spoke (cpa edwardsville = 0 vol, cpa naperville = 90 vol). Architecture: 2 campaigns with tight geo fences, head terms + suburb-specific + near-me ad groups.

Two prerequisites before API deploy
1. MCC invite: Thompson Flaherty's Google Ads account is not yet connected to Markology MCC 8210062698. Athar (or whoever owns the account) needs to send a manager access invitation. Without this, the campaigns cannot deploy via Pipeboard API and must be built manually.

2. Gravity Forms confirmation type: The contact form on thompsonflaherty.com/contact/ uses Gravity Forms. Default behavior is in-place "Thank you" message. Easiest conversion tracking = configure GF to redirect to /contact/?submitted=1 or /thank-you/ on submit, then we use a codeless Page view conversion (URL contains submitted). See Step 0 below.
Step 0 - Pre-launch (conversion tracking)

Set up the Gravity Forms conversion

Same pattern as Ashford Sky. Codeless Page view conversion fires when someone lands on the post-submit URL.

  1. In Gravity Forms, set the Contact form confirmation to a URL redirect
    WordPress admin -> Forms -> Contact form (form ID 2) -> Settings -> Confirmations. Change the default "Text" confirmation to Redirect and set the URL to https://thompsonflaherty.com/contact/?submitted=1 (or build a dedicated /thank-you/ page). Save.
  2. Verify the redirect fires
    Submit a test entry on the live page. Confirm the browser lands on the redirect URL. Delete the test entry from Forms -> Entries afterward.
  3. In Google Ads, create the codeless Page view conversion
    Tools & Settings -> Conversions -> + New conversion action -> Website. Enter https://thompsonflaherty.com/contact/?submitted=1 -> Scan -> when asked "What event should this track?" choose Page load / Page view. URL rule: URL contains submitted=1 (or /thank-you if you build that page). Category: Submit lead form. Primary: Yes. Count: One. Save.
  4. Add the Call Extension as a secondary conversion
    Phone calls from ads via Google's free call-forwarding number count automatically. Add (618) 656-6010 as a Call asset on both campaigns and set "Calls from Ads" as a secondary conversion (60-second minimum threshold).
  5. Verify with Tag Assistant
    Submit one more test form with Chrome's Google Tag Assistant extension running. Confirm the Page view conversion event fires on the redirect URL.
Why codeless Page view and not gtag form-submit event?
Codeless Page view uses the existing Google Tag (one-line install). No need to wire gtag('event', 'conversion', ...) into Gravity Forms' confirmation hook, which would require either a plugin or theme code. Same pattern that worked for Ashford Sky on 2026-05-14.

  • If < 5 conversions: review search terms, ad relevance, consider broadening keyword set or geo
  • If CPL is acceptable on either campaign: propose scaling that one to $50-75/day
  • If Chicago is significantly more expensive per lead than STL: rebalance budget toward STL
