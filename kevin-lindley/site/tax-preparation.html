Tax Preparation Questions We Get Asked

How do I file an extension?+

We file Form 4868 for you electronically, and you'll get confirmation once it's accepted. An extension only gives you more time to file. Any tax you owe is still due by the April deadline, so we estimate that before the extension goes in.

I filed my S-corp election and never got a confirmation letter. Is that a problem?+

Not necessarily. I can pull your IRS transcript or call the IRS to check whether the election is on file. If it was never accepted, the IRS has a late election relief process, and it can usually be fixed with the return.

Can you take over a return someone else started?+

Yes. Send what's been done along with the source documents. I'll review it before I build on it, because I'd rather catch a problem now than carry it forward.

Do I have to file in another state if I worked there for a few days?+

It depends on the state and the amount. Some states want a return for any income earned there, and others have thresholds. Tell me where you worked, and we'll check that state's rules before deciding.
