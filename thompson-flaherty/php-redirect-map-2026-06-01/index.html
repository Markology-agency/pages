How to import

  1. Log into thompsonflaherty.com/wp-admin/
  2. Go to Rank Math > Redirections
  3. Click the Import & Export tab at the top
  4. Under Import, choose the downloaded CSV file
  5. Click Import
  6. Confirm the 20 new redirects appear in the Redirections list
  7. Test 2-3 of them in incognito (e.g. thompsonflaherty.com/tax.php should land on /tax-business/)
Note: the 6 redirects that already work correctly (/about.php, /contact.php, /services.php, /index.php, /home.php, /faq.php) are not in this CSV. Importing them would create duplicate rules.
