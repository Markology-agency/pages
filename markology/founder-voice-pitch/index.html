Founder-voice libraries + per-client deliverables

Central directory for the Markology founder-voice system: live library viewers, pipeline walk-throughs, content calendars, and social plans, one per client.

What is the founder-voice library?

A daily extraction pipeline that mines client Fireflies meeting transcripts (with the client's permission and API key) and files structured, tagged, anonymized entries into a per-client corpus. Downstream Markology skills (writing, social, content-calendar) read the corpus when drafting so client content sounds like the actual founder, not generic agency filler.

For the architecture, costs, and onboarding flow, see Departments/Operations/founder-voice/SKILL.md on Whitney's machine.
