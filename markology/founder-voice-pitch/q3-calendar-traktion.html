How these 12 topics were chosen

  1. Pulled the full Traktion sitemap (59 published blogs), filtered to in-niche (excluded Texas-local and lawyer-vertical per Traktion CLAUDE.md).
  2. Queried Asana for in-flight work (Internal Review, Edits Needed, Client Review, In Progress, Not Started). Caught a parent task "[SEO] Ship 6 therapist-niche articles for Q2 cluster expansion" with full SEO briefs for 6 unpublished blogs. THREE of the initial proposed Q3 topics conflicted with these briefs and were swapped (slots 1, 5, 9).
  3. For each library topic with 3+ entries, identified the closest existing OR in-flight blog by title + slug. Computed an overlap score.
  4. Net-new gaps (library has rich material, NO existing or in-flight blog): proposed straight from library entries.
  5. Overlapping topics: required a clearly differentiated angle the library supports. Either a different audience cut, a different decision-frame, or a process/instructional angle the existing/in-flight blog doesn't take. If no differentiated angle existed in the library, the topic was skipped.
  6. Voice fidelity: every proposed H2 outline pulls directly from library entries (founder takes, vocabulary, social quotes). Drafts will sound like Mebea by construction, not by interpretation.

Lesson incorporated: The first draft of this calendar checked only the sitemap and would have shipped 3 cannibalizing topics (W-2 vs 1099, hiring break-even, S-corp election). Asana check caught all three. The /quarterly-content-calendar skill now requires BOTH sitemap + Asana queries before any topic is finalized.

What this test shows about the founder-voice library + content calendar skill

The library + sitemap + Asana cross-reference works. The two-source cannibalization check (sitemap for published, Asana for in-flight) is what makes this trustworthy. Without the Asana step, three of these twelve topics would have shipped on top of unpublished drafts already in the queue.

What the test surfaces:

  • Net-new topic gaps: insurance reimbursement cash-flow, revenue forecasting for variable income, tax-savings-account banking practice, monthly financial review cadence, hidden costs of S-corp compliance. All have library material but no published OR in-flight blog.
  • Differentiated angles on covered topics: the safe-harbor method specifically, mid-year entity switching as a process, EHR-payout categorization mechanic, post-hire 90-day operational playbook, S-corp distribution + estimated tax misconception. All have rich library support and don't duplicate published or in-flight blogs.
  • Voice fidelity by construction: every H2 outline is built from Mebea's actual stated takes and vocabulary, not from generic SEO templates. The drafting agent inherits voice automatically because the source material IS the voice.

The honest caveat: this Q3 calendar was generated from a library seeded by 4 blogs of reverse-extracted content. Once Fireflies starts feeding in real meetings, the library will get richer and proposed topics will reflect what prospects are actually asking about. That's where this gets really strong: net-new content topics driven by repeat prospect questions (pain points, FAQs) the team can see emerging in real time.
