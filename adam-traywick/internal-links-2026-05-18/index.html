Behind the scenes

How It Shipped

Two stacks involved — Gutenberg block posts for 8 of 9 source pages, Elementor for the FAQ page. Each required a different push path.

Gutenberg posts (8 of 9)

Standard WordPress REST API POST /wp/v2/{posts|pages}/{id} with browser User-Agent header (iThemes Security Pro on this site 403s default python-requests/2.x). Three initial passes needed smart-quote and phrasing corrections before all matches landed.

Elementor FAQ page

The accordion stores Q&A content inside _elementor_data JSON as nested text-editor widgets. Patched the JSON string in-place, then DELETE /wp-json/elementor/v1/cache to flush Elementor's render cache — without that step, DB updates persisted but the rendered page kept serving stale HTML.
