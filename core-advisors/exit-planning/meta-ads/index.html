Campaign notes

What sits behind the four ads, and what has to be true before any of it runs.

Why exit planning at all

  • This account's wall is "I already have a guy." Tax and bookkeeping ads run straight into it. Exit planning walks around it, because almost no dentist's current CPA is talking to them about transferable practice value.
  • The ad isn't asking them to fire anyone. It's naming something their current advisor has never raised. That's a much cheaper click.
  • It also reframes Core from "dental accountant" (sticky, replaceable) to "the team that makes your practice sellable."

The funnel

  • Ad → exit-planning LP → inline valuation calculator → result showing the gap → book a call with Jeremiah.
  • EPI's own framework says the triggering event for every exit-planning engagement is a business valuation. Core already has that tool, so the front door already exists.
  • Ads carry no dollar figures, so the LP and calculator do the number work where the disclaimer lives with it.

Guardrails

  • Compliance. Core is a registered investment advisor. No promised outcomes, no guaranteed valuations, no implied sale prices. Nothing in these ads promises a number.
  • Stat discipline. Every EPI figure is all-industry. Ads say "business owners," never "dentists." This is the same discipline as the tax-accuracy gates and it is not negotiable.
  • Two-client firewall. Thomas Gore and Jeremiah Barwick both work at Core Advisors and Keen Capital. Never reference Keen in Core creative.
  • Targeting. Change one lever at a time on this narrow B2B audience. We've moved too fast on dentist audiences before.
  • Emotional lane. Upside and FOMO only. Regret and the 5 Ds are deliberately excluded from the cold set. If a variant starts drifting toward fear, it's off-brief.
  • Cold interest-targeting to "dentists" stays off for now. The June strategy flags it as weak with brutal CPL. Lookalike and retargeting first.
