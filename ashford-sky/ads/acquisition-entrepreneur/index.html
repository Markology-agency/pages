Why Manual CPC and not Maximize Conversions?
No conversion history on the account. Smart bidding needs ~15 conversions in 30 days to learn. Manual CPC for 30 days, then switch to Maximize Conversions (or Target CPA once we know the CPL) after the first 15 booked calls.
Why a single Search campaign and not Performance Max?
Acquisition entrepreneurs are a small, high-intent search niche. They're typing specific queries ("search fund CPA", "quality of earnings small business") — Search captures that exact intent without burning budget on Display / Discover / YouTube placements where pMax would scatter the spend.
Step 0 - Pre-launch

Set up the Calendly booking conversion action

None of the existing 4 conversion actions are mapped to the /thank-you/ redirect. Create a new URL-based conversion action so you don't have to install gtag on a Calendly thank-you page.

  1. In Google Ads, go to Tools & settings → Measurement → Conversions
    Click + New conversion action → Website.
  2. Enter the domain
    Enter ashfordsky.com. If Google Ads has scanned the site, you'll get the option to add a conversion action from a URL. If not, click Add a conversion action manually.
  3. Configure the conversion action
    Goal: Contact (Submit lead form works too — both feed the same goal category).
    Conversion name: Acquisition Calendly Booking
    Value: Don't use a value (we can revisit once CAC is known).
    Count: One
    Click-through window: 30 days
    Attribution model: Data-driven (default).
  4. Set the URL trigger
    Match type: URL contains
    URL: /thank-you
    This fires the conversion any time someone lands on the post-Calendly thank-you page.
  5. Verify the trigger fires
    Open https://ashfordsky.com/acquisition-entrepreneur/ in an incognito window, book a fake Calendly slot (you can cancel right after), and confirm the redirect lands on a URL containing /thank-you. Check Google Ads → Conversions in 24-48 hours to confirm 1+ conversion logged.
Heads up on the other 4 conversion actions
"Send a message", "Click Contact Us", "Submit lead form", and "Sign-up" all exist as gtag-event types. They're fine to leave enabled — they won't fire for this campaign unless the snippets are installed somewhere on the site. Set only the new "Acquisition Calendly Booking" as the campaign's optimization goal.

Pre-launch checklist

Don't enable the campaign until every box is checked.

  • "Acquisition Calendly Booking" conversion action created and verified firing on /thank-you/
  • Existing 2 paused campaigns confirmed still paused
  • Campaign settings match the table above (especially: Search only, Presence targeting, Manual CPC)
  • All 3 ad groups built with max CPC = $5.00
  • All keywords added with correct match types (phrase + exact, no broad)
  • 6 RSAs uploaded (2 per ad group), each with 15 headlines + 4 descriptions
  • Pinned headlines locked to position 1 per RSA
  • Shared negative keyword list created and attached to campaign
  • 4 sitelinks, 8 callouts, structured snippet, and call extension attached
  • Final URL points to /acquisition-entrepreneur/ with UTM suffix
  • "Acquisition Calendly Booking" set as the campaign's conversion goal (the other 4 conv actions excluded)
  • Daily budget = $15.00

Day 7 check-in

  • Pull Search Terms Report - add new negatives for any non-buyer queries
  • Check impression share lost (rank). If >30%, raise max CPC by $1 in steps
  • Check ad strength on all 6 RSAs - aim for "Good" or "Excellent"
  • Confirm conversion column is firing (even if 0 conversions yet)

Day 30 decision point

  • If ≥ 15 conversions: switch to Maximize Conversions (no tCPA cap), let Smart Bidding take over
  • If 5-14 conversions: stay on Manual CPC, adjust bids on top converting keywords +20%
  • If < 5 conversions: review search terms + ad relevance, consider broadening Ad Group 2 keywords, do not increase budget yet
  • If CPL is acceptable to Darin, propose scaling to $30-50/day
