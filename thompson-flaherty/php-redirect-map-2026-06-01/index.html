RANK MATH UI.

Rank Math's bulk Redirections is the cleanest fix. ~5 minutes of clicking total. WP Admin → Rank Math → Redirections → Add New → paste each pair below.

/tax.php → https://thompsonflaherty.com/tax-business/ 301 /tax-services.php → https://thompsonflaherty.com/tax-business/ 301 /payroll.php → https://thompsonflaherty.com/payroll/ 301 /bookkeeping.php → https://thompsonflaherty.com/bookkeeping/ 301 /accounting.php → https://thompsonflaherty.com/accounting/ 301 /cfo.php → https://thompsonflaherty.com/cfo-services/ 301 /qoe.php → https://thompsonflaherty.com/qoe-service/ 301 /audit.php → https://thompsonflaherty.com/qoe-service/ 301 /exit-planning.php → https://thompsonflaherty.com/exit-planning/ 301 /about-us.php → https://thompsonflaherty.com/about/ 301 /contact-us.php → https://thompsonflaherty.com/contact/ 301 /team.php → https://thompsonflaherty.com/about/ 301 /staff.php → https://thompsonflaherty.com/about/ 301 /news.php → https://thompsonflaherty.com/news/ 301 /blog.php → https://thompsonflaherty.com/news/ 301 /clients.php → https://thompsonflaherty.com/about/ 301 /testimonials.php → https://thompsonflaherty.com/about/ 301 /resources.php → https://thompsonflaherty.com/news/ 301 /pricing.php → https://thompsonflaherty.com/tax-business/ 301 /sitemap.php → https://thompsonflaherty.com/sitemap_index.xml 301
Source URL format in Rank Math: use Source Type = "Exact". Each pattern goes in without the leading slash for some Rank Math versions; verify by previewing one and seeing what saves. Comparison mode "Exact" means only the listed URL is rewritten, not any URL that starts with that path — which is what we want for these specific legacy URLs.
